# Manuscripta

**Read. Reshape. Resonate.**

Manuscripta is a Windows reader that presents a plain-text book like a visual novel.
The text is typed out frame by frame (a frame is four paragraphs), and in the
illustrated mode every scene gets a picture generated by a server and shown above
the text.

## Features

- Two reading modes, switched in the start menu (the choice is remembered):
  - **Text only** — a tall reading panel, no network access.
  - **Illustrated** — a picture for each scene above a short text panel. The next
    scene is requested in advance, so its picture is usually ready when you get there.
- Remembers the last frame of every book and resumes from it.
- Opens `.txt` files in UTF-8, UTF-16 LE/BE (with BOM) or the system code page.
- Resizable, DPI-aware window.

## Controls

| Action | Keys / mouse |
| --- | --- |
| Next (finish typing, then next frame) | Click, `→`, `Enter`, `PgDn` |
| Previous frame | Right-click, `←`, `Backspace`, `PgUp` |
| Pause / resume typing | `Space`, pause button |
| Scroll a long frame | Mouse wheel, `↑` `↓` |
| Text size | `+` `−` |
| Typing speed | `[` `]` |
| Back to the menu | `Esc`, ✕ button |

## Building

Requirements: Visual Studio 2022 with the *Desktop development with C++* workload
(toolset v143, C++20, Windows 10 SDK).

Open `Manuscripta.vcxproj` and build, or from a Developer Command Prompt:

```
msbuild Manuscripta.vcxproj /p:Configuration=Release /p:Platform=x64
```

Every push is built by GitHub Actions; the resulting `Manuscripta.exe` is attached
to the workflow run as the `Manuscripta-x64` artifact.

## Scene server

In the illustrated mode the app sends each scene to a server:

```
POST <SceneApiUrl>
Content-Type: application/json

{ "text_chunk": "<text of the scene>" }
```

and expects

```json
{ "data": { "image": "<URL of a PNG or JPEG>" } }
```

The default URL is `http://vps72250.hyperhost.name/api/scene/getScene`. To use
another server, set the string value `SceneApiUrl` under
`HKEY_CURRENT_USER\Software\Manuscripta`; an `https://` URL uses TLS.

## Settings

Stored under `HKEY_CURRENT_USER\Software\Manuscripta`:

| Value | Meaning |
| --- | --- |
| `TextOnly` | 1 — text-only mode, 0 — illustrated |
| `FontSize` | Text size in points (10–32) |
| `Speed` | Characters typed per 20 ms tick (1–10) |
| `SceneApiUrl` | Scene server URL |
| `Positions\<file path>` | Last frame read in that book |

| `SceneFetcher.*` | Request to the scene server (WinHTTP) |
| `ImageLoader.*` | Downloads and decodes a scene picture |
| `FileLoader.*` | File dialog and text decoding |
| `Settings.*` | Registry-backed settings |
| `config.h` | Frame size (`SKIP_ENDS`) and style presets |
